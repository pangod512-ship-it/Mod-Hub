# Mod Hub 1.0.0

First stable public release by pangod512 for Minecraft Java 1.20.1 / Forge 47.4.10–47.x. Client only.

- Vanilla-style, transparent mod browser with responsive columns.
- Search by name, ID and author; filter by compatibility type.
- Mod icons, descriptions, versions and configuration shortcuts.
- Manual type corrections saved per instance.
- Background Modrinth identification enabled by default, with an opt-out and local cache for offline use.
- No mod downloads, updates, toggling or server-pack export.

This is the first public version. Earlier 0.x builds were private development and testing versions. Their private reports and history are not part of this repository.
